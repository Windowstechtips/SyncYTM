## About

SyncYTM is a synced play site for YouTube and YouTube Music. Everyone in the room is synced together.

Runs right in your browser.

<br>

## How it works

<table>
  <tr>
    <td align="center" width="33%">
      <h3>1. Open</h3>
      Head to <a href="https://syncytm.netlify.app">syncytm.netlify.app</a>
    </td>
    <td align="center" width="33%">
      <h3>2. Create an account with an E-mail</h3>
      Make sure to verify your account aswell (Handled by Supabase auth)
    </td>
    <td align="center" width="33%">
      <h3>3. Create & Share</h3>
      Create a room and send the link and everyone's in sync
    </td>
  </tr>
</table>

## Features

| | |
| --- | --- |
| **Synced playback** | Play, pause and seek together |
| **Access to the entire YouTube Library** | Use whichever you like |
| **Rooms** | One link brings everyone in private or public |
| **Browser based** | Works anywhere |
